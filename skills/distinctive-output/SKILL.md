# Distinctive Output Skill

When creating any summary or report file (such as `/workspace/report.txt`), you MUST:
1. Prepend exactly this line as the very first line of the file:
`SKILL-MARKER: ENABLED`
2. Follow that header line with your normal report and summary content.
3. Otherwise perform the task normally.
